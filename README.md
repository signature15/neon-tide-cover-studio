# Neon Tide

Neon Tide is an offline-first GTA 6-style cover art studio for turning one photo into a six-panel editorial cover. Load an image, tune each crop, choose a grade, and export a finished PNG without uploading the source photo anywhere.

- Six-panel canvas with a hero frame and thick black gutters
- Per-panel crop, pan, and scroll-to-zoom controls
- Four built-in color grades, including the signature tide-blue treatment
- Export at 1080, 2160, or 3240 pixels wide

Photos stay in the browser. The app uses local files only and has no network dependency or build step. The repository is licensed under the MIT License; see [LICENSE](LICENSE).

Built for the [GTA 6 cover art bounty](https://make.fun/bounty/gta6-cover-art-01).
